# Document messages

**Status:** Accepted, 2026-10-14. The labels the API prints on its documents, in Spanish (default) and English. The
register of the error codes is [messages.md](messages.md).

A document is built once and stored, so it keeps the language it was built in.

| Key | `es` (default) | `en` |
|---|---|---|
| `document.title` | Comprobante de orden | Order receipt |
| `document.warehouse` | Almacén | Warehouse |
| `document.number` | Orden | Order |
| `document.due_date` | Fecha de entrega | Due date |
| `document.customer` | Cliente | Customer |
| `document.contact` | Contacto | Contact |
| `document.lines` | Materiales | Materials |
| `document.line_code` | Código | Code |
| `document.line_name` | Material | Material |
| `document.line_unit` | Unidad | Unit |
| `document.line_quantity` | Cantidad | Quantity |
| `document.created_by` | Creada por | Created by |
| `document.operators` | Surtida por | Picked by |
| `document.validated_by` | Validada por | Validated by |
| `document.signature_delivers` | Entrega | Delivers |
| `document.signature_receives` | Recibe | Receives |
| `document.signature_line` | Nombre y firma | Name and signature |
